# 쿼터뷰 전환 기준

> 2026-09-21 기준. `feat/quarter-view-pivot`의 1차 플레이어블 전환 범위다.

## 좌표와 물리

- 월드 X/Y가 이동 평면이며 Rigidbody2D 중력은 0이다.
- 이동 입력은 길이를 1로 제한해 대각선 속도를 보정한다.
- 대시는 이동 입력을 우선하고, 정지 상태에서는 마지막 조준 방향을 사용한다.
- 플레이어 루트 Transform은 반전하지 않는다. 시각 SpriteRenderer만 `flipX`를 사용해 자식 히트박스 좌표를 보존한다.
- 바닥 Tilemap은 시각 전용이고, 벽 Tilemap만 충돌을 가진다.

## 조준과 공격

- 마우스는 화면 좌표(`<Pointer>/position`)를 월드 좌표로 변환한다.
- 게임패드는 오른쪽 스틱을 사용하며 데드존 아래에서는 이동 방향을 마지막 조준으로 채택한다.
- 근접 히트박스, 슬래시 VFX, 서브무기 판정은 같은 `AimDirection`을 사용한다.

## 방 템플릿

- `#`: 이동 불가 벽
- `.`: 이동 가능한 바닥
- `D`: 문. 외곽에서 허용되는 유일한 개구부
- `-`: 이전 템플릿 호환용 바닥
- 마커와 확률 셀은 해석 후 이동 가능한 바닥이어야 한다.

검증기는 8방향 flood fill을 사용하되, 두 직교 이웃 중 하나라도 막혔으면 대각선 모서리를 통과하지 않는다. 모든 문 내부 셀과 마커가 같은 연결 영역에 있어야 한다.

## 이번 단계에서 의도적으로 제외한 것

- 적 AI의 쿼터뷰 전용 행동과 충돌 튜닝
- 완성형 전투/퍼즐 방 콘텐츠
- 쿼터뷰 아트, 깊이 정렬용 최종 스프라이트와 애니메이션

현재 `Assets/Rooms/*.txt`는 이동·문 전환·렌더링을 검증하는 오픈형 그레이박스다.

## 검증 기준

- EditMode: 이동 벡터, 대시 방향, 조준 기하, 평면 도달성, 템플릿 전량, 씬 배선
- PlayMode: 프로토타입 씬 로드, 던전 시작 방 생성, 플레이어 물리, 바닥 충돌 비활성
- Windows: `QuarterViewPrototype` 단일 시작 씬 빌드
